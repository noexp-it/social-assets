# noexp.it - social assets

Public copies of graphics for noexp.it social media posts. They live here so the scheduling tool (Buffer) can download them by URL. Everything in this repo is already public, or will be once its post goes out.

Sources, generators and post texts stay in our private knowledge base. Nothing else belongs here: no drafts, no data, no credentials.

One folder per post: `YYYY-MM-DD-<post>/`, named after the publication date.
